# Anniversary Arissa Zulaikha 💖

Website 6 bulan. Halaman: Beranda, Foto, Impian Kita.

## Buka di VS Code
1. File > Open Folder > pilih folder ini
2. Install ekstensi "Live Server", lalu klik kanan index.html > Open with Live Server

## Ganti foto
Taruh arissa1.jpg sampai arissa6.jpg di folder ini (sejajar index.html).

## Push ke GitHub
git init
git add .
git commit -m "anniversary arissa"
git branch -M main
git remote add origin https://github.com/USERNAME/anniversary-arissa.git
git push -u origin main

## Buka di HP
Deploy gratis lewat Vercel atau GitHub Pages, lalu buka link-nya di HP.
